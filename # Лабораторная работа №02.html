Среда выполнения

  • ОС: Rocky Linux 10.2
  • Оболочка: Bash
  • Инструменты: Git, GitHub

Создание и работа с ветками

  • Создание ветки: git branch <имя_ветки>
  • Переключение на ветку: git checkout -b <имя_ветки>
  • Слияние веток: git merge <исходная_ветка>
  • Удаление ветки: git branch -d <имя_ветки>

Теги

  • Создание тега: git tag -a v1.0.0 -m "сообщение"
  • Удаление тега: git tag -d v1.0.0
  • Отправка тегов: git push --tags

Игнорирование файлов

  • Файл .gitignore в корне репозитория
  • Примеры шаблонов:
    • *.log
    • *.tmp
    • .idea/
    • __pycache__/
    • .DS_Store

Просмотр истории

  • git log — полная история
  • git log --oneline — краткая история
  • git log --graph — графическое отображение
  • git log --all — все ветки

Работа с удалённым репозиторием

  • Добавление удалённого репозитория: git remote add origin <URL>
  • Отправка изменений: git push -u origin main
  • Просмотр удалённых репозиториев: git remote -v
